# Slide Content Extraction

Load this reference when turning long copy, files, or brand proposals into slides.

## Extraction Pass

Build a concise slide spine before creating visuals:

| Field | Purpose |
| --- | --- |
| Slide title | The claim the audience should remember |
| Source points | Source bullets or sections supporting the claim |
| Proof object | Matrix, flow, package, KPI, persona, chart, or image |
| Visual role | Background, diagram, table, timeline, hero, or callout |
| Editable elements | Text, shapes, connectors, tables, labels |
| Risk / note | Missing data, compliance, source caveat |

## Compression Rules

- Use the source document for substance, not as slide copy.
- Keep one main idea per slide.
- Turn lists into matrices, funnels, timelines, or packages when that improves comprehension.
- Use short client-ready language rather than internal notes.
- Avoid unsupported numbers. Use ranges only when the source supports a range or when clearly marked as suggested.

## Common Slide Objects

- Brand diagnosis: problem / business impact / fix / metric matrix.
- Brand anchor: positioning, audience, value, trust reasons, USP.
- Market insight: red ocean vs blue ocean, platform role map.
- Audience: persona strips or segmentation table.
- Journey: awareness-to-conversion-to-referral funnel.
- Content system: pillar matrix, sample hooks, platform roles.
- AIGC workflow: production pipeline from intake to review.
- Offer: Basic / Growth / Performance package matrix.
- KPI: 30 / 60 / 90 day roadmap.
- Compliance: risk control checklist and human review workflow.
