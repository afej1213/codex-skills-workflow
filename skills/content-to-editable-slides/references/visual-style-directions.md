# Visual Style Directions

Load this reference when the user has not specified a visual style.

Offer exactly three directions and wait for confirmation before image generation:

1. **Premium editorial**  
   Cinematic generated visuals, refined typography, dark or warm premium palette, suitable for client strategy proposals and high-end brand decks.

2. **Modern commercial**  
   Clean, bright, structured layout with clear sales logic, suitable for proposals, service packages, product explainers, and management presentations.

3. **Social-first creative**  
   Bolder hooks, lifestyle visuals, content-calendar energy, TikTok/Reels campaign feel, suitable for social media and creator-led brand strategies.

When the user chooses a direction, translate it into:

- palette
- image prompt style
- slide layout rhythm
- type hierarchy
- image-safe areas
- density level
